# کریپتو مسنجر ۰.۱.۰ — راهنمای نصب و راه‌اندازی

## ۱. پیش‌نیازها

این نسخه آزمایشی برای سیستم‌های Linux طراحی شده و به موارد زیر نیاز دارد:

- کامپایلر GCC یا Clang
- کتابخانه و سرآیندهای OpenSSL
- کتابخانه و سرآیندهای SQLite3
- کتابخانه و سرآیندهای GNU libmicrohttpd
- کتابخانه و سرآیندهای json-c
- ابزار Make

در Debian و Ubuntu:

```sh
sudo apt update
sudo apt install build-essential pkg-config libssl-dev libsqlite3-dev libmicrohttpd-dev libjson-c-dev
```

## ۲. ساخت برنامه

در پوشه اصلی پروژه اجرا کنید:

```sh
make
```

فایل اجرایی در مسیر زیر ساخته می‌شود:

```text
build/crypto-messenger
```

## ۳. اجرای برنامه

```sh
./build/crypto-messenger
```

سپس در مرورگر این نشانی را باز کنید:

```text
http://127.0.0.1:8080
```

سرور فقط روی آدرس محلی دستگاه (Loopback) گوش می‌دهد و از شبکه محلی یا اینترنت قابل دسترسی نیست.

## ۴. روش استفاده

۱. زبان فارسی یا انگلیسی را انتخاب کنید.
۲. متن موردنظر را وارد کنید.
۳. یک عبارت عبور قوی وارد کرده و آن را تأیید کنید.
۴. دکمه «رمزنگاری» را بزنید.
۵. خروجی را کپی کنید یا به‌صورت فایل `.cmsg` ذخیره کنید.
۶. برای بازکردن پیام دریافتی، متن رمزنگاری‌شده را وارد کنید یا فایل `.cmsg` را بارگذاری کنید؛ سپس همان عبارت عبور را وارد کرده و «رمزگشایی» را انتخاب کنید.
۷. برای ذخیره خروجی رمزنگاری‌شده در بانک اطلاعاتی، دکمه «ذخیره در بانک اطلاعاتی» را بزنید.

گیرنده باید نسخه سازگار برنامه و همان عبارت عبور را داشته باشد. عبارت عبور را از مسیری جداگانه و امن برای گیرنده ارسال کنید.

## ۵. پایگاه داده

برنامه فایل زیر را ایجاد می‌کند:

```text
data/messenger.db
```

در این نسخه، فقط محتوای رمزنگاری‌شده با عملیات ذخیره در بانک اطلاعاتی ثبت می‌شود.

## ۶. نکات امنیتی

- برای رمزنگاری از AES-256-GCM استفاده شده است.
- کلید از عبارت عبور با PBKDF2-HMAC-SHA-256 مشتق می‌شود.
- برای هر بار رمزنگاری، Salt و Nonce تصادفی جدید تولید می‌شود.
- از عبارت عبور طولانی و غیرقابل حدس استفاده کنید.
- عبارت عبور را همراه پیام رمزنگاری‌شده ارسال نکنید.
- این سرور صرفاً برای آزمایش محلی طراحی شده است.
- این نسخه هنوز ممیزی امنیتی مستقل نشده است.
- رمزنگاری کلید عمومی و پیوست‌های باینری در نسخه ۰.۱.۰ پیاده‌سازی نشده‌اند.

## ۷. توقف برنامه

در ترمینال کلیدهای `Ctrl+C` را فشار دهید.

## ۸. رفع اشکال

اگر هنگام کامپایل، نبودن یک کتابخانه گزارش شد، بسته توسعه مربوط به آن را مطابق بخش اول نصب کنید.

اگر درگاه ۸۰۸۰ اشغال است، سرویس دیگری را که از آن استفاده می‌کند متوقف کنید.
